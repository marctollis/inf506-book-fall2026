14  Accessing Data: Spreadsheets, Databases, Arrow, JSON, and Web Scraping

14.1 Learning Objectives

By the end of this lecture, you should be able to:

  • Import and work with data from Excel and Google Sheets
  • Connect to and query relational databases from R
  • Use Arrow to work efficiently with parquet files and large datasets
  • Access and tidy hierarchical JSON data
  • Perform basic web scraping to extract data from web pages

16 Databases (R4DS Chapter 21)

Relational databases store data in tables that can be queried without loading the entire dataset into memory.

In R, the DBI package provides a common interface for working with databases. Here we will use RSQLite to create a small SQLite database from the familiar nycflights13 data.

16.1 Hierarchical Data and JSON

Many datasets are not stored as rectangular tables. Instead, they may contain nested objects, lists, or repeated values.

This is common with data returned by web APIs.

JSON stands for JavaScript Object Notation and is a widely used format for storing and exchanging hierarchical data.

16.2 Creating a small JSON example

We will create a small nested dataset in R and save it as JSON.

library(tidyverse)
library(jsonlite)

students <- list(
  list(
    name = "Ana",
    program = "Biology",
    scores = c(88, 92, 95)
  ),
  list(
    name = "Ben",
    program = "Informatics",
    scores = c(78, 85, 91)
  ),
  list(
    name = "Cara",
    program = "Biology",
    scores = c(94, 96, 98)
  )
)

write_json(
  students,
  "students.json",
  pretty = TRUE,
  auto_unbox = TRUE

students_df <- students_df |>
  unnest_wider(student)

students_long <- students_df |>
  unnest_longer(scores)

students_long |>
  group_by(name, program) |>

    mean_score = mean(scores),

JSON → nested R object → tibble → unnest → tidy data

17.1 HTML Elements

HTML pages are made of elements marked by tags.

For example:

<h1>This is a heading</h1>
<p>This is a paragraph</p>

Here: - <h1> represents a heading. - <p> represents a paragraph.

Elements can also have attributes such as id and class.

html <- minimal_html("
  <h1>This is a heading</h1>
  <p id='first'>This is a paragraph</p>
  <p class='important'>This is an important paragraph</p>

# Databases (R4DS Chapter 21)

Relational databases store data in tables that can be queried without loading the entire dataset into memory.

### In-Class Exercise 2

In this exercise, you will create a small SQLite database from the `nycflights13::flights` data, connect to it, and query it using familiar `dplyr` verbs.

```{r}
library(DBI)
library(RSQLite)
library(dplyr)
```

Step 1: Create the database Create a new SQLite database file called `flights.sqlite`.

```{r}
con <- dbConnect(
  SQLite(),
  "flights.sqlite"
)
```

Step 2: Write the `flights` table to the database

```{r}
dbWriteTable(
  con,
  "flights",
  flights,
  overwrite = TRUE
)
```

Check that the table was created:

```{r}
dbListTables(con)
```

Step 3: Create a reference to the database table

```{r}
flights_db <- tbl(
  con,
  "flights"
)

flights_db
```

Note that flights_db is a reference to the database table. The full dataset has not been copied into R.

Step 4: Query the database Find all flights with departure delays greater than 120 minutes.

Keep only these variables: - carrier - flight - origin - dest - dep_delay

```{r}
delayed_flights <- flights_db |>
  filter(dep_delay > 120) |>
  select(
    carrier,
    flight,
    origin,
    dest,
    dep_delay
  )

delayed_flights
```

```{r}
delayed_flights |>
```

```{r}
delayed_flights_df <- delayed_flights |>
```

## Hierarchical Data and JSON

Many datasets are not stored as rectangular tables. Instead, they may contain nested objects, lists, or repeated values.

This is common with data returned by web APIs.

JSON stands for **JavaScript Object Notation** and is a widely used format for storing and exchanging hierarchical data.

## Creating a small JSON example

We will create a small nested dataset in R and save it as JSON.

```{r, eval=FALSE}
library(tidyverse)
library(jsonlite)

students <- list(
  list(
    name = "Ana",
    program = "Biology",
    scores = c(88, 92, 95)
  ),
  list(
    name = "Ben",
    program = "Informatics",
    scores = c(78, 85, 91)
  ),
  list(
    name = "Cara",
    program = "Biology",
    scores = c(94, 96, 98)
  )
)

write_json(
  students,
  "students.json",
  pretty = TRUE,
  auto_unbox = TRUE
)
```

Reading JSON

```{r}
students_json <- jsonlite::read_json(
  "students.json",
  simplifyVector = FALSE
)

students_json
```

Inspect the object:

```{r}
str(students_json)
```

Notice that this is not yet a rectangular data frame.

*Converting hierarchical data to a tibble* Start by placing each student record into a row:

```{r}
students_df <- tibble(
  student = students_json
)

students_df
```

*Widening nested objects* Use `unnest_wider()` when named elements of a nested object should become columns.

```{r}
students_df <- students_df |>
  unnest_wider(student)

students_df
```

The `name` and `program` fields are now columns, but `scores` is still a list column.

*Lengthening repeated values* Use `unnest_longer()` when multiple values should become multiple rows.

```{r}
students_long <- students_df |>
  unnest_longer(scores)

students_long
```

Now each score appears in its own row.

*Summarizing the tidy data*

```{r}
students_long |>
  group_by(name, program) |>
  summarize(
    mean_score = mean(scores),
    .groups = "drop"
  )
```

The main workflow is:

JSON → nested R object → tibble → unnest → tidy data

# Web Scraping with HTML

Web scraping means extracting information from web pages.

Web pages are written in **HTML** (HyperText Markup Language). HTML is hierarchical: elements can be nested inside other elements.

In R, the `rvest` package provides tools for reading and extracting information from HTML.

```{r, eval=TRUE}
library(rvest)
```

*Reading HTML* Use read_html() to read HTML from a web page:

```{r}
url <- "https://rvest.tidyverse.org/"
html <- read_html(url)

html
```

The result is an HTML document that we can query with `rvest`.

We can also create a small HTML document directly in R:

```{r}
html <- minimal_html("
  <h1>This is a heading</h1>
  <p>This is a paragraph</p>
  <ul>
    <li>This is a bulleted list</li>
  </ul>
")

html
```

## HTML Elements

HTML pages are made of elements marked by tags.

For example:

```         
<h1>This is a heading</h1>
<p>This is a paragraph</p>
```

Here: - `<h1>` represents a heading. - `<p>` represents a paragraph.

Elements can also have attributes such as `id` and `class`.

```{r}
html <- minimal_html("
  <h1>This is a heading</h1>
  <p id='first'>This is a paragraph</p>
  <p class='important'>This is an important paragraph</p>
")
html
```

## Selecting HTML Elements

Use `html_elements()` to select all matching elements.

```{r}
html |>
  html_elements("p")
```

This selects all `<p>` elements.

## Select by class

A period `.` selects elements by their class attribute:

```{r}
html |>
  html_elements(".important")
```

## Select by ID

A hash `#` selects an element by its id attribute:

```{r}
html |>
  html_elements("#first")
```

The basic selector rules are: - `p` selects HTML tags - `.class_name` selects a class - `#id_name` selects an ID

## `html_element()` vs. `html_elements()`

`html_elements()` returns all matching elements.

```{r}
html |>
  html_elements("p")
```

`html_element()` returns the first matching element for each input.

```{r}
html |>
  html_element("p")
```

## Extracting text

Selecting an element gives us the HTML element itself.

To extract its visible text, use `html_text2()`:

```{r}
html |>
  html_elements("p") |>
  html_text2()
```

## Extracting Attributes

Sometimes useful information is stored inside HTML attributes rather than in the visible text.

For example:

```{r eval=FALSE}
html <- minimal_html("
  <a href='https://www.example.com'>Example website</a>
")
```

Select the link:

```{r eval=FALSE}
link <- html |>
  html_element("a")
```

Extract the visible text:

```{r eval = FALSE}
link |>
  html_text2()
```

Extract the `href` attribute:

```{r eval = FALSE}
link |>
  html_attr("href")
```

This distinction is important when scraping real websites: some information is visible on the page, while other information is stored in the HTML structure or attributes.

## Extracting HTML Tables

Many web pages contain tables that can be converted directly into data frames.

Use `html_element()` to select a table and `html_table()` to convert it:

```{r}
library(rvest)

page <- minimal_html("
  <table>
    <tr>
      <th>Name</th>
      <th>Score</th>
    </tr>
    <tr>
      <td>Ana</td>
      <td>92</td>
    </tr>
    <tr>
      <td>Ben</td>
      <td>85</td>
    </tr>
  </table>
")

table <- page |>
  html_element("table") |>
  html_table()

table
```

## Web Scraping Workflow

A typical web scraping workflow is:

1\. Read a web page with read_html().

2\. Inspect the HTML structure.

3\. Select elements with html_elements() or html_element().

4\. Extract text with html_text2(), attributes with html_attr(), or tables with html_table().
